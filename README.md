A simple and responsive Expense Tracker Web App built using HTML, CSS, and JavaScript. This project helps users manage their daily income and expenses while automatically calculating the available balance.

🚀 Features
➕ Add new income and expenses
💵 Track total income
💸 Track total expenses
📊 Calculate balance automatically
🗑️ Delete transactions
🔄 Real-time UI updates
📱 Responsive design
💾 Store transaction data using Local Storage.
